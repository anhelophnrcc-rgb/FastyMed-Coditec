# FastyMed-Coditec# FastyMed - Ecossistema Digital Farmacêutico 💊
Projeto acadêmico desenvolvido para a **Coditec (Fatec Franca)**.

## 📱 Funcionalidades Principais
* Busca inteligente de medicamentos e comparador de preços em farmácias de Franca-SP.
* Módulo de validação clínica digital (Conformidade com Anvisa RDC 44/2009 e ICP-Brasil).
* Acompanhamento de pedidos em tempo real com rotas simuladas.

## 💻 Responsividade
Este protótipo foi desenvolvido com design totalmente responsivo, funcionando livremente e com adaptação automática tanto em **Dispositivos Móveis (Celulares/Smartphones)** quanto em **Desktops (Computadores e Notebooks)**.
